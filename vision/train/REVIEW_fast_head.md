# Correctness review

- **P2 — vision/train/fast_head.py:45–49,61:** Files are shuffled/split independently without deduplication, so copies of one image can enter training and validation/test. The supplied Commons images contain byte-identical, readable pairs (e.g. `duster_02.jpg` / `eraser_05.jpg`); their split placement depends on earlier source counts/RNG consumption. This can contaminate model selection and reported accuracy. **Fix:** group duplicates across all sources (including `pi_testset`) before splitting; reserve groups containing fixed test images for test, and keep all augmented views with their original group.
- **P2 — vision/sorti_model.py:40–45:** v2 availability checks only labels and head weights. If those exist but the referenced feature `.pte` is absent, construction tries to load it and raises instead of providing the documented v1 fallback. **Fix:** check the referenced feature model exists before selecting v2; otherwise load v1 metadata and model.
